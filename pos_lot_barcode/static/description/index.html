POS Lot Barcode Module

This module enables scanning of serial numbers and lot numbers directly in Odoo 18 Point of Sale (POS).

Main Features

  • Support for serial and lot numbers in POS
  • Automatic validation upon scanning
  • Seamless integration with Odoo 18 POS

Installation

Copy the module into the Odoo addons directory and activate it in the Odoo settings.

Compatibility

Tested with Odoo 18.
